使用说明

0. 三个模式：「连续立体」做棱柱 / 棱锥 / 棱台 / 圆柱 / 圆锥 / 圆台 / 球 / 椭球 / 正多面体（四·六·八·十二·二十面体）；「立方体阵列」做 2³~6³ 小方块拼成的大立方体；「正方体涂鸦」给正方体六个面自由画图并按 11 种展开图摊平。
0.1 光滑体：圆柱 / 圆锥 / 圆台 / 球 / 椭球按真实曲面着色，口沿和轮廓是光滑曲线，不再显示一段段等长的折线；想调网格粗细请到「显示选项 › 曲面细分」，球与椭球用「经线 / 纬线密度」。
0.2 参数：球调半径 R；椭球调三个半轴 a / b / c（相等就是球）；正多面体调外接球半径 R 并在下拉里换种类，下方会显示面 / 棱 / 顶点数。
0.3 一键截面：右栏「一键截面」列出这个立体实际能切出的形状（带 ✓ 的是已验证的），点一下直接切，滑块自动跟随；点「↻ 精扫全部可能」会做一次更仔细的搜索。
1. 建模：拖滑块 / 填数值 / 直接拖动画布彩色手柄（R 底面半径、k 顶面缩放、h 高度、a 阵列整体尺寸）。
2. 阵列编辑：选「涂色 / 挖除 / 填回」后单击或按住拖动小方块，鼠标所指的一格会先描边预览；快捷按钮可一键「统一单色 / 只留外壳 / 挖去中心 / 逐层配色」。填回时虚线框出的是将被恢复的空位（原有颜色保留）。透视剖层可把外层暂时拿掉，用来涂上／挖掉被包在里面的方块，点「恢复完整」即变回实心大立方体。此时右键拖动仍可旋转。
2.1 长按瞄准：自己挑要填哪一块。填回画笔下，长按约 0.4 秒屏幕上的某个空位 → 这条视线上的所有空位都被锁定并列出来，底部弹出瞄准条：
· 目标块画成实心淡绿框并标「目标」；它前面挡着的实心块标橙色「前」、后面的标蓝色「后」，三者之间用白虚线连起来——一眼看清你要填的那块夹在哪两块之间；
· 瞄准条上 1 2 3 … 直接点你想填的那一块（编号从你最先看到的那块算起），也可左右拖动换层；
· 长按后可以松手，此时照常拖动就能转视角，从侧面确认位置，再点「填这块」提交；点「取消」或换画笔即退出；
· 提交后会有一圈绿色脉冲标出刚填回去的那块——内部的块被挡住看不见，靠它确认确实生效了。
另外，「填回层次」条上的方向按钮可把编号顺序切成「由外向内 / 由内向外」，配合瞄准条按需使用。
3. 常见截面：右栏选水平 / 铅垂 / 倾斜，调参即时呈现。
4. 自定义截面：切回「浏览取点」，在表面单击取点（自动吸附顶点/棱；点偏一点也不会落空——鼠标 16px、手指 28px 内会吸附到最近的面，轻触手抖也不再被当成旋转），或在「按棱取点 / 坐标输入」里精确添加；≥3 点后点「确定截面」。
5. 校验：不共面、近似共线都会明确提示并说明偏离量。阵列的截面是按小方块一格一格画出来的，格线就是方块分界；涂过色的块在截面上仍是自己的颜色，挖空的格子如实空着（就是洞）。挖掉任意数量、任意位置的小方块后照样能切：轮廓连不成闭合环时自动切成「逐块截口」，一个方块一格，截面积按格相加、周长只算外边界。
6. 涂鸦：点任一空白面→放大绘制（画笔/橡皮、撤销、清空）→「保存并返回」；左栏可换展开图并「展开 / 合好」，展开态同样能点面继续画。默认按所见即所画处理：展开图上怎么画，返回后就怎么显示，展开 / 合好时贴图跟着面一起转。
